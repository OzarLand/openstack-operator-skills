# openstack-operator-skills has moved

Nine Agent Skills that make Claude reason like a senior OpenStack operator during incidents, changes, maintenance and
troubleshooting, with a validation status for every procedure.

It is now **Operator skills**, the step *Equip* of **OzarLand Academy**, the learning path of
[OzarLand](https://github.com/OzarLand/ozarland):

- **Read it:** <https://academy.ozarland.com/skills/>
- **Sources, with their whole history:** [OzarLand/ozarland-academy](https://github.com/OzarLand/ozarland-academy),
  under [`docs/skills/`](https://github.com/OzarLand/ozarland-academy/tree/main/docs/skills)
- **Issues and contributions:** [OzarLand/ozarland-academy](https://github.com/OzarLand/ozarland-academy/issues)

The skills are still a Claude Code plugin, with the same names; its marketplace is now ozarland-academy. In Claude
Code:

```text
/plugin marketplace add OzarLand/ozarland-academy
/plugin install openstack-operations@openstack-operator-skills
```

If you added this repository as a marketplace before, remove it (`/plugin marketplace remove
openstack-operator-skills`) and add ozarland-academy instead: this repository no longer receives updates.

This repository is archived: it keeps its history and its issues up to the move, read-only. Every page of it has
its copy, with the same history, in ozarland-academy, where the pages now link to each other across the modules of
the academy.
