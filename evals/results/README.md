# Raw evaluation results: not advice

These files are the raw output of the behavioural evaluations described in [../README.md](../README.md): model
answers, grades and run metadata, kept so that the published scores can be checked.

**Do not use them as operational guidance.** Many answers are *baseline* runs made without the skills on purpose,
and some contain errors the grader flagged as critical. Paths such as `/tmp/osk-eval-*` are throwaway directories of
the evaluation harness.

For guidance, use the skills themselves and the
[OzarLand runbooks](https://github.com/OzarLand/openstack-vm-runbooks).
